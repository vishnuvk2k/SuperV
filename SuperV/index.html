Ease

Drag the two handles or pick a preset. Selected keys eases between neighbouring selected keyframes; All keys eases every keyframe on the selected properties. The result is normal After Effects easing you can still adjust in the Graph Editor.

Loop

Select properties with at least two keyframes.

Wiggle position

Edit Wiggle Speed and Wiggle Amount in Effect Controls at any time.

Rotate forever

No keyframes. 360° per second is one full turn each second. Orbit circles around where the layer sits now. Change speed and radius later with the sliders in Effect Controls.

Depth

Turns the selected 2D layers into 3D and spaces them along Z for a parallax look. If the comp already has a camera, that camera is used. Undo puts everything back.

Number counter

Uses selected text layers, or makes a new one. 3 / 3 gives 1,500,000 and 3 / 2 gives 15,00,000.

Comp size

SmartResize moves, scales and re-aims everything for the new frame, including keyframes, motion paths and cameras. Layers inside a parent follow the parent. Layers whose Position or Scale is driven by an expression are skipped and counted.

Animate text

SuperV
Slide up

In runs from the layer start to its "in" marker; Out runs from its "out" marker to the layer end. Drag the markers to change timing. Your font is kept.

Background box

Adds a rectangle behind each selected text layer with equal padding on every side. It follows the text as you type, resize or move it. Edit Padding and Roundness later in Effect Controls.

Split text

Each piece becomes its own layer in the same place. Works on point text without Source Text keyframes. Up to 300 pieces.

Change case

Rewrites the text of the selected text layers, including Source Text keyframes.

Typewriter with cursor

Types the text in from the layer start to its "in" marker, with a cursor following the last letter. Drag the marker to change speed.
